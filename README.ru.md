# Phase Pal Music Bridge

[English](README.md) · [简体中文](README.zh-CN.md) · [Русский](README.ru.md) · [Español](README.es.md) · [日本語](README.ja.md)

Расширение связывает воспроизведение в браузере с функцией **Dance to Music** в Phase Pal. Необязательный анализ ритма выполняется на вашем устройстве. Проект поддерживает Consistency AI.

**Предварительная версия:** исходный код открыт по лицензии MIT; для изображения кролика действуют отдельные условия. Это не выпуск в Chrome Web Store и не подписанный установщик Phase Pal. Нужна совместимая настольная версия приложения со встроенным браузерным мостом; она сюда не входит. Проверки реального воспроизведения в Chrome и собранного приложения ещё не завершены.

## Возможности

Расширение передаёт состояние воспроизведения и паузы из Spotify Web, YouTube Music, SoundCloud, Apple Music, региональных плееров Amazon Music, Deezer, TIDAL, Qobuz, Pandora, Yandex Music, QQ Music, KuGou, JioSaavn, LINE MUSIC, Bugs, JOOX, Anghami и Audiomack. См. [точные адреса и пределы проверки](docs/SUPPORTED_SITES.md). Через **Custom websites** можно добавить отдельный сайт, предоставив доступ к нему в Chrome; см. [настройку сайтов](docs/CUSTOM_SITES.md).

Воспроизведение на поддерживаемом сайте считается музыкой. Речь, подкасты и реклама тоже могут вызывать танец: расширение не различает песни и речь. Ограничения учётной записи, подписки, региона, защищённого содержимого и плеера сохраняются. Перед полноценным выпуском нужны проверки этих интеграций с реальным воспроизведением.

## Использование

1. Используйте Chrome 116 или новее в Windows или macOS и совместимую сборку Phase Pal, которая включает и регистрирует браузерный мост. Текущий процесс установки не поддерживает Linux и другие браузеры. Обновление расширения само по себе не добавляет мост в старое приложение.
2. Для этой версии скачайте `phasepal-music-bridge-preview-0.1.0.zip` со страницы [Releases](https://github.com/ConsistencyAI/phasepal_extension/releases) и распакуйте его. Включите **Developer mode** на `chrome://extensions`, нажмите **Load unpacked** и выберите папку с `manifest.json`. Отдельный ZIP для магазина предназначен для панели разработчика и не содержит публичного ключа разработки.
3. Откройте Phase Pal и включите **Dance to Music**. Запустите воспроизведение на поддерживаемом или одобренном вами сайте и откройте окно расширения, чтобы проверить соединение.
4. Нажмите **Enable Beat Sync**, чтобы анализировать звук этой вкладки локально. Chrome показывает индикатор захвата, а звук вкладки остаётся слышен. **Stop Beat Sync** завершает захват.

**Auto Beat Sync** по умолчанию выключен и сохраняется только на этом устройстве. Если он включён, открытие окна расширения на готовой музыкальной вкладке вызывает одну попытку захвата. Одобренный поток может сохраняться во время пауз и смены треков на том же сайте. Новая вкладка или завершённый поток требуют нового вызова расширения либо нажатия Enable; настройка не разрешает захват без участия пользователя. Захват прекращается при Stop, отключении Auto Beat Sync или Dance to Music, потере связи с приложением или разрешения сайта, уходе с сайта, закрытии вкладки либо завершении потока.

Напоминание на сайте направляет к кнопке расширения на панели инструментов. **Not now** скрывает его для текущего документа; **Don't show again** сохраняет локальную настройку для всех сайтов и после перезапуска. Отключение или удаление расширения прекращает передачу состояния воспроизведения.

## Локальная обработка данных

Звук вкладки, включая речь и рекламу, анализируется в памяти расширения. Доступ к микрофону, запись в файл, расшифровка речи, аналитическая телеметрия и удалённая загрузка не используются. Локальное приложение Phase Pal получает только фиксированные флаги воспроизведения и идентификаторы сервисов, признаки наличия метаданных, поля сеанса и протокола, а также числовые характеристики ритма. Названия песен, имена исполнителей, URL, текст страниц, история браузера и исходный звук не передаются. Источники добавленных сайтов и две настройки остаются в Chrome локально. У Phase Pal, Chrome и музыкальных сервисов есть собственные правила обработки данных; см. [полное описание границ](docs/PRIVACY.md).

## Сборка и проверки

Нужны Node.js 22.12+ в ветке 22.x либо Node.js 24+, npm и сохранённый в репозитории lock-файл:

```bash
npm ci
npm run check
```

Загрузите полученную папку `dist/` как распакованное расширение. Его идентификатор разработки должен быть `depmepnaojmbbjgogihalfgeajkfkbjj` и соответствовать нативному хосту `app.phasepal.music`. Публичный ключ в манифесте фиксирует этот ID и не является секретом.

См. [команды разработки и нативного хоста](docs/DEVELOPMENT.md), [дизайн V1](docs/DESIGN.md) и [правила участия](CONTRIBUTING.md). Пользователям совместимого собранного приложения не нужны Rust, Python и ручная установка хоста. Для разработки хоста нужны Rust 1.85+, Python 3 и инструменты сборки платформы.

```bash
cargo test --manifest-path native-host/Cargo.toml --locked
npm run package:store
```

Для упаковки нужен Python 3. Оба ZIP и контрольные суммы записываются в `BuildArtifacts/chrome-web-store/0.1.0/`. Предварительный ZIP сохраняет ключ разработки, а пакет для магазина удаляет его. Проверьте назначенный Google ID магазина и согласуйте обе копии исходного кода нативного хоста и регистрацию приложения до распространения приложения для этого ID. Нативный исполняемый файл не включён. Локальные тесты не проверяют настоящий захват в Chrome или собранное приложение. CI не настроен.
