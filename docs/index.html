Set up the preview

Use Google Chrome 116 or newer on Windows or macOS. The current install workflow does not support Linux or other browsers.

  1. Check your Phase Pal build

    Open a compatible desktop build that includes the music bridge, and turn on Dance to Music. The app registers its own bridge with Chrome. An older app does not gain this integration just by updating the extension. Ordinary users of a compatible packaged app do not need Rust, Python, or manual host commands.

  2. Load the preview extension

    Download phasepal-music-bridge-preview-0.1.0.zip from GitHub Releases and extract it. Open chrome://extensions, enable Developer mode, select Load unpacked, and select the extracted folder containing manifest.json. The separate store-upload ZIP is for the developer dashboard.

  3. Play something in Chrome

    Start playback on a supported music website. Open Chrome's Extensions menu and select Phase Pal Music Bridge. Pin it if you want quick access. Check the popup's actual connection status.

  4. Choose Beat Sync

    Select Enable Beat Sync to analyze the active supported tab. Chrome shows a capture indicator and the tab remains audible. Select Stop Beat Sync to end capture. Estimates depend on the audio; a detected player does not prove the sound is music.

Your music websites

Built-in integrations cover Spotify Web, YouTube Music, SoundCloud, Apple Music, Amazon Music regional players, Deezer, TIDAL, Qobuz, Pandora, Yandex Music, QQ Music, KuGou, JioSaavn, LINE MUSIC, Bugs, JOOX, Anghami, and Audiomack. Account, subscription, region and player restrictions still apply. See exact hosts and verification limits.

For another site, expand Custom websites in the popup, enter its address and choose Add website. Chrome requests access to that exact site. Refresh the tab if needed. Site access allows playback observation; starting tab audio capture still needs the popup action. Remove the site in the popup to revoke its optional permission and stop its capture.

Speech, podcasts, ads and videos may also trigger dancing. The bridge is not a song or speech classifier and does not bypass protected content.

You control capture

Auto Beat Sync is off by default and saved locally. With it on, opening the popup on a ready tab attempts capture once. The approved stream can continue through pauses and same-site track changes. A new tab or ended stream needs a new extension invocation or Enable click. This setting never grants unattended capture.

Capture also ends when you turn Auto Beat Sync off, turn Dance to Music off, lose the app connection or site permission, leave the site, close the tab, or end the stream. A site's reminder only directs you to the popup. Not now dismisses it for the current document; Don't show again saves a local preference.

Tab capture includes speech and ads from that tab. Audio is processed in memory; the extension does not request microphone access, record audio to a file, transcribe speech, or upload audio. Read the extension privacy policy.

Connection help

Phase Pal is unavailable

Start a compatible app build and enable Dance to Music. If the bridge is missing, update to a build that includes it. Restart the app and Chrome after an update. The preview development extension ID is liinajbmlphpehjkmjdffpjhajdpgfpm and the native host is app.phasepal.music; a mismatched ID will not connect.

Beat Sync is unavailable or shows no stable beat

Focus the intended supported or approved custom tab, start playback, and reopen the popup. Check Chrome's site permissions. Suspended audio, silence, speech, irregular rhythm and protected media can prevent useful estimates. Exact BPM values are not guaranteed.

I want to stop or remove it

Select Stop Beat Sync to stop audio analysis. Disable or remove the extension at chrome://extensions to stop playback reporting too. Removing the extension removes its Chrome-local settings and registrations. The separate app and its files are managed separately.

For help, contact hello@consistencyai.net. Include extension and app versions, operating system, and the visible error. Please do not send raw audio, account credentials, or private browser content.
